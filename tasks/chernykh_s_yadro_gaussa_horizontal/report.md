## 1. Introduction
Параллельная реализация горизонтального фильтра Гаусса на базе MPI предназначена для ускорения процесса зашумления изображений высокого разрешения путем одновременной обработки независимых строк данных на нескольких вычислительных узлах.

## 2. Problem Statement
Реализовать алгоритм внесения изменений в изображение с использованием горизонтального ядра Гаусса, обеспечив корректную работу на границах и высокую скорость обработки через параллелизм MPI.

## 3. Baseline Algorithm (Sequential)
В данной версии используется фиксированное ядро Гаусса размером 3×3, которое применяется к каждому пикселю изображения. Проверяется соответствие размеров входного вектора произведению ширины на высоту. Выходной вектор инициализируется тем же размером, что и входной. Используется стандартная матрица с центральным весом 4, осевыми весами 2 и угловыми весами 1 (общая сумма весов — 16). Алгоритм последовательно проходит по каждой строке и каждому столбцу изображения. Для каждого целевого пикселя (j,i) вычисляется взвешенная сумма значений в окрестности 3×3. С помощью std::clamp индексы соседних пикселей ограничиваются диапазонами [0,stroki−1] и [0,stolbci−1]. Это дублирует значения крайних пикселей при выходе за пределы изображения, предотвращая ошибки доступа к памяти. Результирующая сумма делится на 16 (суммарный вес ядра), что обеспечивает сохранение общей яркости изображения.
## 4. Parallelization Scheme
Основная идея заключается в разделении строк изображения между доступными процессами MPI.
Rank 0 вычисляет количество строк для каждого процесса. Если общее количество строк не делится нацело на количество процессов, остаток равномерно распределяется между первыми процессами. Размеры изображения (ширина и высота) рассылаются всем процессам. Для корректного вычисления свертки 3×3 на границах разделенных блоков каждому процессу необходима одна дополнительная строка сверху и одна снизу от соседних процессов. Для передачи фрагментов изображения используется MPI_Scatterv с учетом перекрытия. Это позволяет каждому процессу получить все необходимые данные для вычисления своей области за одну операцию. Каждый процесс вызывает функцию `GaussFilter`, обрабатывая только "свои" чистые строки, используя соседние как вспомогательные. Сбор обработанных локальных результатов обратно на rank 0 процесс в единый вектор `GetOutput()`.
